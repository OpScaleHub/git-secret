keyfold-controller is running as {{ include "keyfold.fullname" . }} in {{ .Release.Namespace }}.

Seal secrets to this controller AND an offline recovery key (and yourself),
so no single key is ever the only way in -- best from a committed keyring:

  keyfold seal --namespace <ns> --name <name> --keyring envs/<env>/keyring.yaml \
    --from-env-file app.env > gitsecret.yaml
  kubectl apply -f gitsecret.yaml          # or commit it for your GitOps tool

This controller's fingerprint and public key:

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "keyfold.fullname" . }} | grep -m1 -o '"fingerprint":"[0-9A-F]*"'
{{- if .Values.publishPublicKey.enabled }}
  kubectl -n {{ .Release.Namespace }} get configmap {{ .Values.publishPublicKey.configMapName }} -o jsonpath='{.data.publicKey}'
{{- end }}
