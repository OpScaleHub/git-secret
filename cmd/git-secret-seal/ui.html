git-secret · seal

Produce a GitSecret manifest. Public-key only — this page never decrypts, never talks to your cluster, never stores anything.

Review the output, then apply it yourself: kubectl apply -f gitsecret.yaml. Nothing leaves this page until you do.
Target
Recipients

Full 40/64-hex GPG fingerprints. The controller's own fingerprint plus every human who should be able to decrypt. Pre-filled from the keyring if one is configured.
